# Murdah Dub Siren

The first dub siren built to play live on MPC standalone, like a real physical siren box. Jamaican soundsystem-style siren, perfect for soundclash, pull up, rewind, dancehall intro and reggae.

**Presets (8):**
Classic Two-Tone, Wailing Sine, Laser Zap, Fast Warble, Air Raid, Tempo Siren, Endless Dub, Sound Boy Alarm

**Controls:**
Pitch, Range, Rate, Wave, Time, Repeats, Mix, Volume, Tone, Release, Wobble, Fire, Rate Sync, Time Sync

**How to use:**
Load it as an instrument on your MPC and trigger the siren live with the pads.
